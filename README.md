# NOVA BREACH — Legends Awaken

크롬북의 Chrome 브라우저에서 실행하는 오리지널 3D MOBA 스타일 웹 게임 프로토타입입니다. Three.js를 사용하며, 탑뷰 전장과 챔피언 전투, 미니언 웨이브, 포탑, 넥서스 파괴를 구현합니다.

## 플레이하기

GitHub Pages가 활성화되면 아래 주소에서 실행할 수 있습니다.

- https://1234qwert5.github.io/NOVA-BREACH/

저장소 설정에서 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택하고, 브랜치는 `main`, 폴더는 `/(root)`로 지정한 뒤 저장하세요.

배포가 완료되면 위 주소를 Chrome에서 여세요. Three.js 모듈을 CDN에서 불러오므로 첫 실행에는 인터넷 연결이 필요합니다.

## 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 챔피언 이동 |
| 마우스 우클릭 | 클릭한 지점으로 이동 |
| 마우스 좌클릭 | 적 지정 및 기본 공격 |
| Q | 아케인 볼트 |
| W | 범위 에너지 폭발 |
| E | 순간 돌진 |
| R | 궁극기 |
| Space | 챔피언 중심으로 카메라 이동 |

## 현재 구현

- Three.js 기반 탑뷰 3D 아레나
- 블루/레드 팀 챔피언과 적 AI
- 미니언 웨이브와 자동 전진·교전
- 양 팀 포탑과 넥서스 오브젝트
- Q/W/E/R 스킬, 마나 및 재사용 대기시간
- 투사체, 피해 판정, 처치/데스, 승리/패배 조건
- Web Audio API로 생성하는 오리지널 전자음악 루프와 전투 효과음
- 체력/마나 바, 스킬 HUD, 전투 타이머

## 참고

이 프로젝트는 MOBA 장르에서 영감을 받은 독립적인 싱글 플레이 프로토타입입니다. 정식 5대5 온라인 게임은 아니며, 리그 오브 레전드의 캐릭터·맵·음악·상표 자산을 복제하지 않습니다.
