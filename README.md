# NOVA BREACH

크롬북의 Chrome 브라우저에서 실행하는 오리지널 3D 전술 FPS 웹 프로토타입입니다. Three.js를 사용하며, 맵과 캐릭터는 코드에서 기본 3D 도형으로 생성합니다.

## 플레이하기

GitHub Pages가 활성화되면 아래 주소에서 실행할 수 있습니다.

- https://1234qwert5.github.io/NOVA-BREACH/

저장소 설정에서 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택하고, 브랜치는 `main`, 폴더는 `/(root)`로 지정한 뒤 저장하세요.

Pages 배포가 완료되면 위 주소를 Chrome에서 열면 됩니다. 첫 실행에는 Three.js 모듈을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

| 키 | 기능 |
|---|---|
| W / A / S / D | 이동 |
| 마우스 | 시점 및 조준 |
| 왼쪽 클릭 | 사격 |
| R | 재장전 |
| Shift | 달리기 |
| Space | 점프 |
| Esc | 마우스 포인터 해제 |

게임 시작 화면에서 **ENTER THE RANGE**를 누른 다음 화면을 클릭해 조준을 시작하세요.

## 현재 구현

- Three.js 실시간 3D 렌더링 및 1인칭 카메라
- WASD 이동, 점프, 달리기, 마우스 포인터 잠금
- 히트스캔 사격, 탄창과 예비 탄약, 재장전
- 추적 및 공격 봇, 처치 수, 체력과 리스폰
- 미니맵과 엄폐물이 있는 훈련장

## 참고

이 저장소는 싱글 플레이 브라우저 프로토타입입니다. 정식 5대5 네트워크 게임, 완성된 상용 FPS 또는 VALORANT의 복제본은 아닙니다. 게임 코드, 캐릭터, 맵, 음원과 상표 자산은 독립적으로 구성합니다.
